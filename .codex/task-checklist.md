# Task Checklist

긴 작업에서 진행 상태를 잃지 않기 위한 프로젝트별 기록 파일이다.

## 현재 작업

- [ ] 목표와 성공 기준을 정리했다.
- [ ] 관련 파일과 기존 검증 명령을 확인했다.
- [ ] 구현 또는 문서 변경을 완료했다.
- [ ] 변경 범위에 맞는 검증을 수행했다.
- [ ] 남은 위험 또는 TODO를 기록했다.

## 운영 규칙

- 비자명한 작업은 계획을 먼저 세운다.
- 구현 변경은 테스트 또는 검증 기준을 먼저 정한다.
- 반복 실수는 테스트, 린트, 훅, CI 같은 자동 검증으로 승격한다.
- 하네스 자체를 바꿀 때는 문제, 예상 효과, 검증, 롤백 방법을 기록한다.
